# 备案操作指南（quizapp.chat）

面向：智题学习笔记小程序 + FastAPI 后端
域名：`quizapp.chat`（阿里云注册，DNS：dns29/dns30.hichina.com）

---

## 一、先搞清楚：你要办两件备案

| # | 备案类型 | 在哪办 | 作用 | 何时必须 |
|---|----------|--------|------|----------|
| 1 | **网站 ICP 备案** | 服务器接入商（阿里云 / 腾讯云）备案系统 | 让 `quizapp.chat` 能作为小程序请求域名使用 | 配小程序服务器域名白名单前 |
| 2 | **小程序备案** | 微信公众平台 → 设置 → 基本设置 → 小程序备案 | 工信部 2023 年起强制，未备案小程序无法上架（存量会下架） | 提交小程序审核发布前 |

两者相互独立，主体信息必须一致，但**可以并行办理**。

> 结论先行：`quizapp.chat` 的 `.chat` 后缀已在工信部批复名单内，可以正常备案，无需换域名。

---

## 二、备案前置条件（缺一不可）

- [ ] **域名**：`quizapp.chat` 已完成实名认证，且**域名持有人 = 备案主体本人**（个人备案要求一致），距离到期日 > 45 天（当前有效期至 2027-09-14，满足）
- [ ] **服务器**：中国内地节点的阿里云 ECS / 轻量应用服务器，**包年包月且时长 ≥ 3 个月**，且有公网带宽
      - 同一阿里云账号下的服务器：备案时自动匹配，无需手动申请备案服务码
      - 服务器在另一个账号下：需先获取「备案服务码」（每台 ECS 最多 5 个免费服务码，一次性使用）
      - 免费试用 / 按量付费的服务器 **不能**用于备案
- [ ] **证件材料**：身份证正反面照片、本人实名手机号（与身份证同名）、常用邮箱
- [ ] **实名核验**：用阿里云 App（或支付宝）扫码做人脸核验
- [ ] 一个阿里云账号只能备案**一个**主体

## 三、网站 ICP 备案流程

入口：https://beian.aliyun.com → 开始备案

1. **基础信息校验**：选服务类型「网站」，填个人校验信息 + 域名 `quizapp.chat`
2. **填写主办者信息**（见下方字段表）
3. **填写网站信息**（见下方字段表）
4. **上传资料 + 真实性核验**：身份证正反面，手机扫码人脸核验
5. **信息确认提交** → 阿里云初审（1~2 个工作日）
6. **工信部短信核验**：初审通过后约 5 分钟收到 12381 短信，**必须在 24 小时内**点链接完成核验，超时自动驳回
7. **管局终审**：3~20 个工作日（多数省份 7~10 天）
8. 收到备案号 → 短信 + 邮件通知

整体周期：**3~22 个工作日**，备案订单本身有效期 45 天。

## 四、备案信息逐字段填写表

### 4.1 主办者信息（个人）

| 字段 | 建议填写值 | 注意事项 |
|------|------------|----------|
| 备案性质 | 个人 | 必须与小程序主体一致 |
| 地区 | 身份证所在地（或常住地，按管局要求） | 决定审核管局，部分省要求与实际居住地一致 |
| 证件类型 | 居民身份证 | — |
| 主办者名称 | 身份证上的姓名 | 必须完全一致，不能有空格 |
| 证件号码 | 18 位身份证号 | — |
| 证件住所 | 身份证上的地址 | 不能自行简化或改写 |
| 通信地址 | 实际常住地址，**精确到门牌号** | 无门牌号：写「××小区×栋×单元」，或按提示填「已为最详细地址」 |
| 手机号码 | 本人实名手机号 | 必须与身份证同名，否则驳回；后续收核验短信 |
| 应急手机号 | 另一个可联系手机号 | 建议填，不要与主号码重复 |
| 电子邮箱 | 常用邮箱 | 接收备案通知与驳回原因 |

### 4.2 网站信息

| 字段 | 建议填写值 | 注意事项 |
|------|------------|----------|
| 域名 | `quizapp.chat` | 只填主域名即可；如后续要用 `www.quizapp.chat` 需单独添加 |
| 网站名称 | `智题学习笔记` | 6 个汉字，用“学习笔记”明确个人记录类工具定位；与小程序名称保持一致 |
| 网站内容 / 服务类型 | 选「其他」 | **不要选教育类**，否则触发教育主管部门前置审批，个人无法提供 |
| 网站语言 | 简体中文 | — |
| 备注（网站用途说明） | 「为微信小程序智题学习笔记提供后端接口服务，包含微信登录、题目数据存储与做题记录统计；不提供新闻、出版、教育等需前置审批的信息服务。」 | 必填项，写得越具体越容易过 |
| 云服务 / 云产品实例 | 选择你的 ECS 或轻量实例 | 需满足「内地节点 + 包年包月 ≥3 个月 + 有公网带宽」 |
| 网站负责人 | 与主办者同一人 | 上传身份证 + 人脸核验 |

### 4.3 网站与小程序统一命名说明

个人备案的网站名称由管局人工审核，规则比企业备案严得多。四条硬规则：

1. **不得含前置审批关键词**：新闻、出版、**教育**、医疗保健、药品、文化、广播影视、电子公告（论坛 / 社区 / 在线 / 交流）等
2. **不得含行业信息、企业信息、产品信息**：商城、交易、购、官网、工作室、科技、中心、学院、系统、服务、咨询（部分省份另有扩充黑名单，如浙江禁「在线 / 工作室 / 官网」，河南黑名单长达 40 余词）
3. **不得纯英文、纯数字、特殊字符**，不能直接用姓名或域名；建议 **4 个汉字以上**，忌用简称
4. **必须与网站实际内容一致**，且符合个人非经营性属性

项目统一使用 **`智题学习笔记`** 作为网站名称和小程序名称：

- 名称为 6 个汉字，满足个人备案通常建议的 4 个汉字以上要求。
- “学习笔记”明确体现个人记录类工具属性，与题目练习、错题复习和学习统计功能一致。
- 网站、小程序、代码界面和隐私说明保持同名，避免备案、审核和用户认知不一致。

提交备案前仍需在接入商和微信公众平台检查重名、禁用词及属地管局的最新规则。若平台要求调整名称，应先确定唯一的新名称，再同步修改备案信息、微信后台和代码，不要同时使用多个产品名。

## 五、小程序备案（微信公众平台）

入口：mp.weixin.qq.com → 设置 → 基本设置 → 小程序备案 → 新增备案

| 字段 | 填写要点 |
|------|----------|
| 备案类型 | 首次备案 |
| 主体信息 | 个人：姓名、身份证号、证件地址、详细通信地址（精确到门牌号）、手机号、邮箱 |
| 小程序信息 | 名称、简介自动带出，需先完善基本信息（名称/图标/描述） |
| **服务类目** | 选与小程序实际功能匹配的类目；**避开「教育 - 在线教育 / 校外培训」**，否则需上传教育部门前置审批文件。个人主体建议「工具 - 效率」或「工具 - 信息查询」 |
| 服务内容描述 | 例：「为个人提供题目练习与错题复习工具，支持上传学习资料生成练习题、顺序/随机练习与模拟考试，并提供学习记录统计。」 |
| 前置审批 | 不涉及（选「不涉及」） |
| 材料 | 身份证正反面 + 小程序负责人人脸核验（本人微信扫码实时拍摄） |
| 承诺书 / 核验单 | 平台生成，在线阅读确认并电子签署 |

**小程序名称单独有规则**：小程序名称与网站备案名称可以不同，但个人主体小程序名称不得涉及企业/单位名义、前置审批领域、国家公共事务，也不得超出个人经营范围。微信在备案入口会做关键词筛选，命中时会直接提示「小程序昵称包含前置审批相关内容，请进行修改」，参考关键词：

> 教育培训、教育咨询、专业技能培训、教育科技、学科类培训、线上培训、**教育**、**培训**（同批还有新闻、金融、证券、保险、出版、图书、医疗、药品、医疗器械、动漫、宗教、网约车、商城、商贸、公司、集团、政务等）

`智题学习笔记` 仍需以微信后台实时校验结果为准。小程序改名有次数限制，改名后还需同步更新备案信息，提交前应先检查重名情况。

**第二条规则：不得用通用词。**《微信小程序平台运营规范》2.5 规定，名称「不能使用广义归纳类、普遍且不具有识别性的词汇」，也禁止关键词堆砌。命名公式应为 **品牌/商标 + 产品类型或功能描述**，例如「啄木鸟维修助手」可过，而「维修助手」「学习助手」「刷题工具」这类纯功能描述会被驳回。个人主体还需避免行业通用词（商城、平台、服务等），建议采用「昵称 + 服务特征」的组合。名称长度控制在 2~10 个汉字为宜。

流程：微信初审（1~2 工作日）→ 工信部短信核验（24 小时内）→ 属地通管局（3~7 工作日，最长 20 天）→ 备案成功，获得备案编号并回填到小程序后台。

## 六、备案通过后必做

1. **域名解析**：阿里云控制台 → 域名 → 解析设置 → 添加 A 记录指向服务器公网 IP（`@` 和 `api` 各一条；建议 API 用 `api.quizapp.chat`）
2. **HTTPS**：申请免费 SSL 证书，配置 Nginx 443 反向代理到后端 8000 端口
3. **小程序白名单**：开发管理 → 开发设置 → 服务器域名，把 `https://api.quizapp.chat` 填入 **request 合法域名** 和 **uploadFile 合法域名**（每月最多修改 5 次）
4. **代码改域名**：`miniapp/app.js` 中 `globalData.baseUrl` 改为 `https://api.quizapp.chat`
5. **悬挂备案号**：网站首页底部展示备案号并链接到 beian.miit.gov.cn
6. **公安联网备案**：备案通过后 **30 日内**，在全国互联网安全管理服务平台提交，ICP 备案是其前置条件

## 七、最容易踩的坑

1. **三主体不一致**：备案主体 = 域名持有人 = 小程序主体，必须是同一个人/同一家公司，否则白名单配不上。
2. **备案期间 80 / 443 端口不能开站**：这段时间用 `IP:8000` 或开发者工具「不校验合法域名」继续调试，不要提前开放公网 443。
3. **短信核验超时**：工信部短信必须 24 小时内处理，很多人卡在这里被驳回。
4. **网站名称踩词**：个人备案禁止出现行业词、企业/产品信息、前置审批词（教育/新闻/出版/文化等）。当前统一使用 `智题学习笔记`，仍需以接入商和属地管局的最终审核结果为准（详见 4.3）。
5. **小程序备案选错类目**：选到教育类会要求前置审批，个人主体无法提供；选「工具」类。
6. **服务器时长不够**：必须包年包月 ≥3 个月，按量付费或试用机不具备备案资格。
7. **一台服务器 ≠ 无限备案**：每台 ECS 仅 5 个免费备案服务码，且一次性使用。
8. **小程序名称含前置审批词**：名称出现「教育 / 培训 / 教育科技 / 线上培训 / 校外培训」等词，备案入口会直接拦截并要求改名，改完才能发起备案。

## 八、备案提交后的行动清单

时间线：阿里云初审（1~2 工作日）→ 工信部 12381 短信核验 → 管局终审（3~20 工作日）→ 备案号下发。

### 等待期间（现在就能做，与审核并行）

1. **盯 12381 短信**：初审通过后约 5 分钟收到核验短信，**24 小时内**必须点链接完成，否则自动驳回（第一优先级）
2. **同步启动小程序备案**：微信公众平台 → 设置 → 基本设置 → 小程序备案，与网站备案互不影响
3. **搭建服务器环境**：`deploy/` 目录已包含整套部署文件
   - `deploy/docker-compose.yml`：MySQL + Redis + 后端 + Nginx 一键编排
   - `backend/Dockerfile` + `backend/.env.production.example`：生产配置模板（含 config.py 的启动校验项说明）
   - `deploy/nginx/quizapp.conf`：含 SSE 关缓冲、50MB 上传限制，备案通过后启用 443
   - `deploy/quizapp.service`：不用 Docker 时的 systemd 守护方案
4. **备案期间 80/443 不开站**：联调放开 compose 里 backend 的 `ports` 映射，用 `http://服务器IP:8000` 测试，备案通过后收回

### 备案号到手后（按顺序，当天可上线）

1. 域名解析：`api.quizapp.chat` A 记录指向服务器公网 IP
2. SSL 证书：阿里云免费证书（有效期 3 个月）或 certbot/acme.sh 自动续期，放到 `deploy/certs/`
3. 启用 Nginx 443 并重载
4. 小程序后台配置 request / uploadFile 合法域名（每月限改 5 次）
5. `miniapp/app.js` 的 `globalData.baseUrl` 改为 `https://api.quizapp.chat`
6. 体验版真机全流程测试 → 提交审核 → 发布
7. **30 日内**完成公安联网备案；网站首页底部悬挂备案号并链接 beian.miit.gov.cn
