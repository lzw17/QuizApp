# 智题学习笔记功能完善方案

> 基于 2026-09 市面主流刷题产品调研（粉笔教师、粉笔快练、猿题库、作业帮、考试宝、华图教师等）
> 结合智题学习笔记现状：11 个页面 / FastAPI 后端，已具备登录、上传出题（AI）、练习、考试、错题本、收藏接口、进度统计

> **2026-09-17 实现状态复核**：错题重做闭环、收藏列表/取消收藏、背题模式、标签/难度筛选组卷、每日一题、连续学习天数和学习报告已落地；隐私页、账号注销、缓存清理和 AIGC 展示提示已落地。用户生成题库当前严格私有，不提供公开分享。AI 内容安全审核、AI 答疑、关于/版本页、笔记和间隔重复仍未实现；未来开放公开题库前，内容审核、人工复核和下架能力是前置条件。

## 二、P0：合规必备（不补无法通过审核）

这一组是上线硬门槛，优先级高于一切新功能：

| 功能 | 改动位置 | 要点 |
|---|---|---|
| 隐私政策页 | 新增 `pages/privacy/` | 展示《用户隐私保护指引》；同时到微信后台「设置 → 服务内容声明 → 用户隐私保护指引」配置（收集了昵称、答题记录，**不配大概率被拒**）；profile 页加入口 |
| 账号注销 | 后端新增 `DELETE /api/auth/account` + profile 入口 | 软删除：置 `is_active=false`、清空昵称头像，答题记录匿名化；二次确认弹窗 |
| 清除缓存 | profile 页设置区 | 清 storage 中题目缓存，**保留 token**；`wx.clearStorageSync` 后重新 `_setSession` |
| AI 内容安全 | `backend/app/routers/upload.py` | DeepSeek 返回后过一遍敏感词过滤（维护一个词表 + 简单匹配即可），命中则拒绝入库并提示；提审时 AI 生成内容是重点检查项 |
| 关于/版本页 | profile 设置区 | 版本号、备案号（网站 ICP 备案下来后悬挂在这里） |

## 三、P1：刷题核心体验（上线后第一批迭代）

### 1. 收藏夹页面（1~2 天，性价比最高）
- 后端 `POST /practice/star` 已存在，只需补：`GET /practice/stars?bank_id=` 列表接口
- 前端新增 `pages/star-book/`（可直接复制 wrong-book 结构）：列表、取消收藏、跳转重做
- 练习页加收藏按钮（答对的好题也值得收藏——粉笔的"错题本管会不会，收藏夹管值不值"分工）

### 2. 错题重做（错题闭环的另一半）
- 后端：`GET /practice/wrong-questions/retry?bank_id=&count=`，从未移除的错题中抽题组一次"错题练习"
- 逻辑按粉笔规则：**重做答对 → 自动移出错题本**（在 `answer` 接口里判断该题是否在错题本，做对即软删除记录）
- 答错的错次 +1，错题本可按"错次"排序，反复错的就是薄弱点

### 3. 背题模式（纯前端）
- 练习页加模式切换：**做题模式**（现状）/ **背题模式**（选项直接高亮正确答案 + 解析展开，点"下一题"推进）
- 背题模式不计入正确率统计，或单独标记

### 4. 智能组卷
- 后端新增 `POST /practice/mock-paper`：参数 `bank_id + 题量 + tags 筛选`
- 抽题策略：优先抽**该用户正确率低的 tags** 下的没做过的题（你的 `tags` 和 `progress` 数据已经支持）
- 入口放在 bank-detail 页："顺序刷 / 随机组卷 / 薄弱专项"三个按钮

### 5. 每日一题
- 后端：按 `date + user_id` 哈希从题库抽 1 题（同一天所有人看到同一题更利于分享）
- index 页顶部卡片展示，答题后显示"明日再来"，做对可点亮打卡

### 6. AI 答疑（追问解析）★ 差异化功能
- 场景：解析看不懂 → 点"追问 AI" → 半屏对话层，预设快捷问题（"为什么 A 是错的""举个生活例子""考点延伸"）+ 自由输入，AI 流式回答
- 后端：新增 `POST /api/ai/ask`（可流式 SSE）——入参 `question_id + user_question`，后端把题干/选项/答案/解析拼进 system prompt，复用 `ai_engine.get_llm()`（temperature 建议降至 0.5）；支持多轮追问（带最近 3 轮历史）
- 三道护栏：
  1. **限次**：每用户 20 次/天（Redis 或 DB 计数），防滥用控成本
  2. **内容安全**：用户输入先过微信 `security.msgSecCheck`（提审硬要求，个人主体可用），AI 输出复用 P0 的敏感词过滤
  3. **上下文收敛**：只带单题上下文 + max_tokens 限制，单次约 1000 tokens，DeepSeek 成本可忽略
- 前端：practice 页解析区加"追问 AI"按钮 → 复用组件做成半屏弹层，SSE 打字机效果（`generating` 页已有 SSE 消费逻辑可参考）
- 延伸方向（同接口可复用）：错题批量"AI 归因总结"、考前"AI 重点串讲"——都放进 P3 储备

## 四、P2：留存与激励（拉日活）

### 6. 打卡 / 连续学习天数
- 后端 `UserStats` 加 `streak_days / last_active_date`，answer 接口顺带更新（跨天则重置或延续）
- profile 统计格加"连续学习 N 天"，index 页打卡入口
- 参考粉笔快练：打卡天数放在头像旁当核心指标

### 7. 学习报告（周报）
- 后端：按日聚合 answer 记录 → 近 7 天做题数、正确率趋势、错误最多的 3 个 tags（薄弱点）
- profile 页新增"学习报告"入口 → 图表页（wx-charts 或纯 CSS 柱状图即可）
- 这是把已有 `stats` 从"3 个数字"升级为"一张可分享的报告"，做完可顺手支持分享到聊天

### 8. 考试倒计时（可选，半天）
- 用户设置一个考试日期（存本地即可）→ index 顶部显示"距考试还有 N 天"
- 备考类产品的经典留存设计

## 五、P3：远期储备（不急）

| 功能 | 说明 |
|---|---|
| 间隔重复（艾宾浩斯） | 错题按 1/3/7/15 天周期提醒重做，做对 3 次降级——粉笔错题本的高阶版，需要定时通知（订阅消息）配合 |
| 笔记功能 | 每题可添加个人笔记，与解析并列展示 |
| 题库分享 | 生成题库口令/二维码，好友可导入同一 AI 题库（注意：分享链接涉及内容责任，建议远期） |
| 导出 PDF | 错题本导出打印 |

**明确不做**：排行榜/社区/问答（个人主体的 UGC 审核负担远超收益）、搜题答疑（与 AI 题库定位不符）、支付/会员（个人主体无支付能力）。

## 六、实施顺序建议

```
本周（与备案等待期并行）：
  P0 合规五件套（隐私政策页 / 注销 / 清缓存 / AI 内容过滤 / 关于页）
下周：
  P1-1 收藏夹  →  P1-2 错题重做  →  P1-3 背题模式
再下一周：
  P1-4 智能组卷  →  P1-5 每日一题  →  P1-6 AI 答疑  →  P2 打卡
上线后第一个迭代：
  P2 学习报告 + 倒计时
```

理由：
1. P0 依赖备案/提审节点，且改动小，先清掉
2. P1 前三项都是小改动大收益（收藏夹几乎零成本），先把"刷题闭环"补完整
3. 智能组卷依赖错题/收藏数据积累后的用户行为，放在闭环跑通之后
4. 打卡/报告属于增长功能，产品稳定后再拉留存
